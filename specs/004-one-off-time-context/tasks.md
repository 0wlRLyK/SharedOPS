## Phase 2: Foundational deadline contract

**Goal**: Provide the shared domain contract for both deadline stories. **Independent test**: `DeadlineTest` exercises variants, construction, calendar projections and overdue boundaries without framework or host timezone dependencies.

- [x] T001 Implement `Deadline` and its regression tests in `backend/src/main/java/dev/sharedops/task/domain/Deadline.java` and `backend/src/test/java/dev/sharedops/task/domain/DeadlineTest.java` according to `specs/004-one-off-time-context/contracts/deadline.md`: distinguish NONE, DATE and DATE_TIME, strict date and named-zone validation, explicit gap/overlap handling, original and projected calendar dates, and open/terminal overdue boundaries. Cover short/long DST days, nonexistent midnight, host timezone restoration, exact comparisons, nulls and invalid inputs. Reject `LocalDate.MAX` via both factories and constructor while evaluating `LocalDate.MAX.minusDays(1)` safely; enforce the inclusive projection-safe instant interval through all creation paths, test endpoints, adjacent nanoseconds, `Instant.MIN/MAX`, named opposite-offset zones and ±18-hour arithmetic. No status mutation or recurrence.

## Phase 5: User Story 3 — Retrieve current account context (P1)

**Goal**: Expose the authenticated account and its active household, or null, with no-store and no cross-account disclosure. **Independent test**: actual authenticated and unauthenticated HTTP requests backed by production-migration PostgreSQL, distinct accounts and memberships, plus contract validation.

- [x] T003 [P] [US3] Implement authenticated context projection, port and use case in `backend/src/main/java/dev/sharedops/household/application/CurrentContext.java`, `backend/src/main/java/dev/sharedops/household/application/CurrentContextStore.java`, and `backend/src/main/java/dev/sharedops/household/application/CurrentContextService.java`, with `backend/src/test/java/dev/sharedops/household/application/CurrentContextServiceTest.java`. Use only `CurrentAccount.authenticatedAccountId()`, call `findForAccount(UUID)`, reject absent identity and missing account through existing authentication failure handling, and test the exact actor passed, returned current projection, null household and failure without disclosure. No request-supplied account or household selector.
- [x] T004 [US3] Implement the actor-scoped single-query adapter in `backend/src/main/java/dev/sharedops/household/infrastructure/persistence/JdbcCurrentContextStore.java` and production-Flyway PostgreSQL tests in `backend/src/test/java/dev/sharedops/household/application/CurrentContextIT.java`. Join active membership in the join condition; return current stored account email and matching household values, nullable icon and null household when membership is absent/inactive. Test distinct synthetic accounts and households, foreign and inactive rows, missing actor, current persisted values and committed state; do not add a schema migration. Depends on T003.
- [x] T005 [US3] Add `GET /api/v1/auth/me` to `backend/src/main/java/dev/sharedops/household/api/AccountController.java` and any focused response type in `backend/src/main/java/dev/sharedops/household/api/`, route-specific pre-security no-store handling in `backend/src/main/java/dev/sharedops/config/security/`, and additive contract in `docs/api/openapi.yml`. Add `backend/src/test/java/dev/sharedops/household/api/CurrentContextHttpIT.java` and `backend/src/test/java/dev/sharedops/household/api/CurrentContextOpenApiIT.java` covering authenticated 200 with stored account/household UUIDs and all fields, null icon and household, inactive and foreign isolation, unauthenticated existing 401 Problem Details with no private data, and `Cache-Control: no-store` on both security rejection and success. Verify OpenAPI required nullable fields, 200/401 and headers; preserve other endpoint/session/CSRF behavior. Depends on T003 and T004.
